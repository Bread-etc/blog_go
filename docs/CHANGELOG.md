# 变更日志 (Changelog)

## [v1.1.2] - 2026-07-28

### ✨ 新增功能 Features

- 新增文章浏览量增加接口，分离原始文章详情中浏览量自增逻辑

### 🧪 单元测试 Test

- 调整文章浏览量增加接口的单元测试
- 调整 Bruno 测试用例集及接口文档

### 📦 构建相关 Build

- 新增容器环境变量配置 `GIN_MODE=release`

## [v1.1.1] - 2026-06-28

### ✨ 新增功能 Features

- 完成 DTO、Model、Service、Controller、Middleware 和 Router 的整体重构，接口字段统一为 `camelCase`
- 新增 Bruno CLI 接口测试集合，覆盖主流程、负向用例和边界用例，默认自动化测试共 84 个请求
- 统一响应结构和业务错误码，修复 Post、Category、Tag 等模块的参数校验、重复数据和关联约束错误语义
- 文章列表`tagIds`同时支持重复参数和 CSV 两种传参方式

### 🛠️ 问题修复 Bugfixes

- 修复`Binding`错误模块识别过于宽泛导致的错误码误判问题
- 修复`Docker Compose`环境变量无法覆盖 Go 配置的问题，支持通过环境变量注入服务端口和数据库配置

### 🧪 单元测试 Test

- 核心 Service 层单元测试已补齐，`go test ./...`通过
- Bruno 全量接口测试已通过

## [v1.1.0] - 2026-04-10

### ✨ 新增功能 Features

- 新增`/api/dashboard/stats`接口，提供文章、分类、标签、友链的总量及月增幅(MoM)百分比统计
- 新增`/api/dashboard/top-posts`接口，支持后台呈现按浏览量倒序排列的热门文章列表
- 文章列表接口新增对`tag_ids`的多标签交集查询支持

### 🛡️ 代码重构 Refactor

- 全面重构 `User`、`Post`、`Category`、`Tag`、`Link` 及 `Config` 模块
- 剥离了响应结构中冗余的时间戳以及敏感的用户信息（如密码、角色详情）

## [v1.0.0] - 2026-01-03

### ✨ 新增功能 Features

- **用户体系**:
  - 基于 JWT 的身份验证与会话管理
  - 实现 RSA 非对称加密登录，保障传输安全
  - 默认管理员账号自动初始化与密码修改功能
- **内容管理 (CMS)**:
  - **文章模块**: 支持 Markdown 内容存储、Slug 友好链接、SEO 优化字段及浏览量统计
  - **分类与标签**: 完整的分类 (Category) 管理与多标签 (Tag) 关联系统
- **运营工具**:
  - **站点配置**: 支持动态修改站点标题、副标题等全局配置
  - **友链系统**: 友链申请、审核与自定义排序 (Sort) 功能

### 🧪 单元测试 Test

- **单元测试**: 对核心 Service 层 (User, Post, Category, Tag, Link, Config) 实现了 **100% 核心逻辑覆盖**
- **测试环境**: 采用 `sqlite` 内存模式模拟真实数据库环境，确保测试的高效性与隔离性
